# 首页“上游”图标替换设计

## 背景

首页服务入口中，“上游”卡片当前使用餐具类图标，与“原辅料采购、仓储”的业务含义不匹配。用户要求仅将“上游”前置图标改为参考图中的“房子 + 百分号 + 托手”线性图标，并保持页面整体风格一致。

## 范围

- 仅影响 `HomeIndustryHomePage` 中 `serviceGroups` 的 `upstream` 入口图标。
- 不修改“中游”“下游”或利企配套服务入口图标。
- 不修改卡片布局、文案、链接、数据接口或后端逻辑。

## 方案

新增一个本地 SVG 静态资源，放在 `frontend/public/historic/icons/` 下，例如 `upstream_home_percent.svg`。图形采用线性描边风格，元素为房屋、百分号和托手；描边颜色使用当前首页入口图标的蓝色主视觉倾向，尺寸由现有 `.hd-home-service-card__icon` 规则统一控制为 38×38。

`HomeIndustryHomePage.jsx` 中仅将 `upstream` 入口的 `icon` 路径从旧图标切换到新增 SVG。

## 测试与验证

- 更新或补充 `home-industry-home-layout.test.jsx`，校验“上游”图标 `src` 指向新增 SVG。
- 保留现有“11 个服务入口图标不重复”的回归断言。
- 运行前端相关测试，必要时运行前端构建，确认没有 JSX/CSS 回归。

## 风险控制

- 新增资源不覆盖现有图片，避免影响其它页面。
- 不调整公共 CSS，避免改变其它服务卡片视觉。
- 图标使用 SVG，缩放清晰，和当前 38×38 图标容器兼容。
